course-material-sync

다시 받은 자료에서 무엇이 바뀌었는지,
이전 파일은 어디에 있는지 알 수 있도록.

시작한 이유

수업 자료가 새로 올라오면 기존 자료와 비교하고 이전 버전도 남기고 싶었습니다. 과목별로 공부를 이어갈 때 어떤 자료가 갱신됐는지 확인할 수 있어야 했습니다. 개인 학습에서 쓰던 자료 자동화 흐름 중 파일 수집 부분을 공개용 CLI로 분리했습니다.

제가 정한 규칙

원본은 남기기

최신 파일로 바꾸더라도 이전 자료를 확인할 수 있도록 보존을 요구했습니다.

변경은 구분하기

새 파일, 바뀐 파일, 그대로인 파일, 실패한 항목을 구분하도록 했습니다.

공개 범위 정하기

계정 정보와 실제 강의자료를 제외하고 도구를 별도 저장소로 공개하도록 했습니다.

같은 파일 두 개를 세 번 확인하면

합성 데이터 실행 기록

처음 실행해서 파일 두 개를 추가했습니다.

added=2  updated=0  unchanged=0
added: lesson-01.txt
added: lesson-02.txt
처음 받기추가 2
변경 없이 재실행동일 2
한 파일 수정 후변경 1 / 동일 1

공개판의 합성 파일로 실행한 기록입니다. 첫 실행, 변경 없는 재실행, 파일 수정 후 결과를 비교합니다.

사용 설명도 수정했습니다

처음 README가 따라가기 어려워 설명 수정을 요청했습니다. 공개판에는 설치, 계정 없이 실행하는 예제, 설정과 문제 해결 안내가 포함되어 있습니다.

확인할 수 있는 것

공개 코드, 실행 예제와 CI 기록을 확인할 수 있습니다. 예제와 CI에서는 합성 파일과 모의 API 응답으로 동작을 검사합니다.

제 역할: 동작 규칙과 공개 범위 결정, 사용 설명 검토. 코드 설계, 구현과 테스트는 AI 코딩 도구가 수행했습니다.

Campus Smash

관악캠퍼스를 걸어 다니며
건물과 차량을 부수는 웹게임입니다.

게임 방향을 정했습니다

설치 없이 PC와 모바일 브라우저에서 플레이하는 게임을 요청했습니다. 정문 주변에서 캠퍼스 전체로 범위를 넓히고, 망치 대신 대포를 사용하는 방식으로 바꾸도록 했습니다.

조작과 공간을 검토했습니다

모바일에서는 이동 패드와 화면 드래그로 시점을 조절하도록 요구했습니다. 건물 외관과 주변 통로는 지도와 사진을 대조하고, 확인한 형태와 추정한 치수를 구분하도록 했습니다.

완성된 게임에서 할 수 있는 것

교내 셔틀 정류장을 골라 시작하고, 대포로 포탄을 발사하며 캠퍼스를 탐험할 수 있습니다. 도로에는 버스와 택시, 승용차가 다닙니다.

공개 배포

GitHub Pages에서 설치 없이 플레이할 수 있습니다. PC와 터치 조작을 지원하며, 그래픽 품질 설정과 파편 수 제한을 갖추고 있습니다.

제 역할: 게임 방향과 기능 범위 결정, 조작과 외관에 대한 수정 요청. 구현에는 AI 코딩 도구를 활용했습니다. 서울대학교의 공식 게임이 아닌 개인 프로젝트입니다.

제 역할

학습할 때 필요한 화면과 동작을 정하고 수정 의견을 전달했습니다. 구현, 검사와 배포는 AI 코딩 도구를 활용했습니다.
